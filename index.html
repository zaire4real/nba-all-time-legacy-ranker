100 分制量化標準

每名球員先得到六個 0–100 的分項分數，再依權重加權成總分。若球員過半生涯處於某獎項尚未存在的年代，該不可觀測分項會記為 N/A 並重新正規化。

預設權重 25 / 25 / 20 / 10 / 10 / 10

1. 巔峰統治力 Peak

  • MVP：4.5 點 / 次
  • All-NBA 1st：0.9 點 / 次
  • All-NBA 2nd：0.25 點 / 次
  • 原始分封頂 25，再換算為 0–100 分項。
Peak = min(25, 4.5×MVP + 0.9×NBA1 + 0.25×NBA2)

2. 季後賽 / 冠軍核心 Playoff Legacy

  • FMVP：4.5 點 / 次
  • 每枚冠軍戒指：0.45 點基礎值
  • 非 FMVP 冠軍會依 MVP / All-NBA 履歷估算「核心冠軍代理值」，避免把 Robert Horry 與第一核心冠軍視為等價。
  • 1969 年 FMVP 設立前的代理修正，會依球員處於該年代的生涯比例縮放。
CoreFactor = min(1.5, .25 + .35×MVP + .12×NBA1 + .05×NBA2)\nEarlyEraProxy = min(8, max(0,Titles−FMVP) × (.4×MVP + .15×NBA1) × PreFMVPShare)\nPlayoff = min(25, 4.5×FMVP + .45×Titles + CoreFactor×max(0,Titles−FMVP) + EarlyEraProxy)

3. 長期頂尖 Sustained Elite

  • All-NBA 1st：1.0 / 次
  • All-NBA 2nd：0.65 / 次
  • All-NBA 3rd：0.40 / 次
  • All-Star：0.25 / 次
Sustained = min(20, NBA1 + .65×NBA2 + .4×NBA3 + .25×AllStar)

4. 防守履歷 Defense

  • DPOY：2.5 / 次
  • All-Defense 1st：0.65 / 次
  • All-Defense 2nd：0.35 / 次
  • 若過半生涯賽季沒有 All-Defense 參評機會，防守分項記為 N/A，不當成 0 分。
Defense = min(10, 2.5×DPOY + .65×DEF1 + .35×DEF2)

5. 生涯長度 Longevity

  • 以 NBA / BAA / ABA 賽季數計算。
  • 16 季以上達到此分項滿分。
Longevity = min(10, 2 + .5×Seasons)

6. 生涯產量 Production

  • 生涯 PPG 最多 5 點
  • RPG 最多 2 點、APG 最多 2 點
  • SPG + BPG 僅以有正式記錄的場次計算；若少於半數生涯賽季可觀測，該 1 點會排除並重新正規化。
  • 產量只佔 10% 預設權重，降低年代與節奏偏差。
Production = min(5,PPG/6)+min(2,RPG/6)+min(2,APG/5)+min(1,(SPG+BPG)/3)

年代修正與模型限制

  • FMVP 自 1969 年開始；All-Defense 自 1968-69 開始；抄截與阻攻自 1973-74 才完整記錄。
  • 模型不直接加入名人堂、人氣、球鞋文化或媒體聲量。
  • 「核心冠軍代理值」仍使用生涯履歷，不是逐年角色判定；此排名是可調權重的透明指數，不是 NBA 官方或經科學證明的定論。
  • 2025-26 PER / WS / WS/48 / BPM / VORP 僅作資訊展示，不納入總分；差距小於 1 分時不應解讀為明確高下。
